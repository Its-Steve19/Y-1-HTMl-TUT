# HTML Notes

Brief study notes covering the fundamentals of HTML5 and webpage structure.

## Topics Covered

- **HTML Introduction:** Meaning, purpose and structure of HTML.
- **HTML Elements:** Tags, opening tags, closing tags and void elements.
- **Document Structure:** DOCTYPE, html, head, title and body.
- **Headings & Paragraphs:** Organizing webpage content.
- **Text Formatting:** Bold, italic, emphasis, subscript and superscript.
- **HTML Comments:** Single-line and multi-line comments.
- **Links & Images:** Hyperlinks, image sources and alt attributes.
- **HTML Lists:** Ordered, unordered and description lists.
- **HTML Tables:** Rows, columns, headers and data cells.
- **HTML Forms:** Input fields, labels, buttons and textareas.
- **Semantic HTML:** Header, nav, main, section, article and footer.
- **HTML Attributes:** IDs, classes, href, src and other element properties.

## Practical Work

Building a simple personal portfolio using HTML only.

## Learning Objective

Understand HTML fundamentals and develop the ability to structure webpages before progressing to CSS and JavaScript.
